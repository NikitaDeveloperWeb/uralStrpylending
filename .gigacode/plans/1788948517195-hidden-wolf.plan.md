# План: Админ-панель + Supabase

## Обзор
Добавление админ-панели с авторизацией, управлением проектами (CRUD), заявками и загрузкой изображений через Supabase (PostgreSQL + Auth + Storage).

---

## ШАГ 1: Установка зависимостей
```bash
npm install @supabase/ssr @supabase/supabase-js
```

## ШАГ 2: Настройка Supabase
1. Создать проект на supabase.com
2. Скопировать URL и API keys
3. Создать файл `.env.local`:
```
NEXT_PUBLIC_SUPABASE_URL=https://xxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbG...
SUPABASE_SERVICE_ROLE_KEY=eyJhbG...
```

## ШАГ 3: Создание таблиц БД
Выполнить SQL в Supabase Dashboard:

**Таблица projects:**
- id (UUID), title, category, area, price, description, features (JSONB), image_url, created_at, updated_at

**Таблица applications:**
- id (UUID), name, phone, email, message, status (new/read/processed), created_at

**Storage Bucket:** `project-images` (public)

**RLS политики:**
- Проекты: публичное чтение, запись только auth
- Заявки: публичное создание, чтение/обновление только auth

## ШАГ 5: Реализация

### 5.1. Клиент Supabase
- `src/lib/supabase/client.ts` — createBrowserClient
- `src/lib/supabase/server.ts` — createServerClient с cookies

### 5.2. Админ-панель
- `/admin/login` — форма входа (email/password)
- `/admin/dashboard` — статистика (кол-во проектов, заявок, последние заявки)
- `/admin/projects` — список проектов с кнопками редактирования/удаления
- `/admin/projects/new` — форма создания проекта
- `/admin/projects/[id]` — форма редактирования
- `/admin/applications` — список всех заявок со статусами

### 5.3. API Routes
- `POST /api/applications` — создание заявки из формы
- `GET /api/admin/projects` — получение проектов (auth required)
- `POST /api/admin/projects` — создание проекта
- `PUT /api/admin/projects/[id]` — редактирование
- `DELETE /api/admin/projects/[id]` — удаление

### 5.4. Компоненты
- `AdminSidebar` — навигация (дашборд, проекты, заявки, выход)
- `ProjectForm` — форма с полями: название, категория, площадь, цена, описание, характеристики
- `ImageUploader` — загрузка изображений в Supabase Storage
